# Your first sprite

This walks through making a small sprite from nothing to an exported PNG.

## 1. Create it

Press <kbd>Ctrl</kbd> + <kbd>N</kbd> (**File → New Sprite…**). Pick a preset such as **32 × 32**, or type a size. Leave the color mode on **RGBA** and the background on **Transparent**, then click **Create**.

## 2. Draw

The **Pencil** (<kbd>B</kbd>) is already selected. Pick a color in the **Color** panel and click on the canvas. Right-click draws with the secondary color; <kbd>X</kbd> swaps the two. <kbd>[</kbd> and <kbd>]</kbd> change the brush size. Mistakes: <kbd>Ctrl</kbd> + <kbd>Z</kbd>.

> **Tip.** Turn on **Pixel perfect** in the options strip for clean 1-pixel lines: it removes the extra corner pixels of a freehand stroke.

## 3. Use layers

Press <kbd>Shift</kbd> + <kbd>N</kbd> for a new layer. Draw the outline on one layer and the colors under it on another. The eye hides a layer; the lock stops edits.

## 4. Animate (optional)

Press <kbd>Alt</kbd> + <kbd>N</kbd> to add a frame, draw on it, then press <kbd>Enter</kbd> to play. <kbd>F3</kbd> turns on onion skin so you can see the frames around the current one.

## 5. Save and export

- **Save** (<kbd>Ctrl</kbd> + <kbd>S</kbd>) writes an `.aseprite` file that keeps layers, frames and tags.
- **Export** (<kbd>Ctrl</kbd> + <kbd>E</kbd>) makes a PNG, a GIF or a sprite sheet for use elsewhere. The dialog shows a live preview.
