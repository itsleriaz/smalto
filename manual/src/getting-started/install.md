# Install

Smalto runs on macOS 13 or later (Apple Silicon and Intel), Windows 10 (1809) or later (64-bit) and Linux (experimental).

## macOS

1. Download the `.dmg`, open it and drag **Smalto** to your Applications folder.
2. The first versions aren't signed by Apple yet, so the first time you open it, **right-click Smalto → Open** and confirm.

## Windows

1. Download the `.zip` and unpack it anywhere (it is portable: nothing is installed).
2. Run `Smalto.exe`. Windows SmartScreen may warn on first run because the app isn't signed yet: choose **More info → Run anyway**.

## Linux

Download the AppImage, make it executable (`chmod +x Smalto-*.AppImage`) and run it. Linux support is experimental.

## Your files and settings

Smalto keeps its settings and a recovery folder in your user data. If Smalto quits unexpectedly, it offers to restore unsaved work the next time you start it.

> **Coming from Gridline?** Smalto was called Gridline until November 2026. On the first launch it takes over Gridline's settings and data once, automatically.
