# Shortcuts

Every keyboard shortcut in Smalto can be changed in **Preferences → Shortcuts**.

## Rebinding a key

1. Open **Preferences** (<kbd>Ctrl</kbd> + <kbd>,</kbd>) and choose **Shortcuts**.
2. Find the action: scroll the list (grouped as Tools, File, Edit, Sprite, Brush and color, View and Timeline), or type in the **Search** box.
3. Click the **+** next to an action to add a key, then press the key (or combination) you want. The row says "Press a key…" while it waits.
4. To remove a key, click the **×** on its chip. To go back to the original keys for one action, click its **reset** button; **Reset all** restores every default.

An action can have more than one key. If a key was already used for something else, it **moves** to the new action and the dialog tells you where it came from, so no two actions share a key.

## Keys that can't be changed

<kbd>Esc</kbd>, <kbd>Enter</kbd>, <kbd>Delete</kbd>, <kbd>Backspace</kbd>, <kbd>Space</kbd> and the arrow keys keep their own jobs (for example <kbd>Esc</kbd> cancels, <kbd>Enter</kbd> plays or applies, <kbd>Space</kbd> pans), so they can't be assigned.

## While you type

Single-key shortcuts (like <kbd>B</kbd> for the pencil) stay out of the way while a text field has focus, so typing a name or a number doesn't switch tools.

## Where keys show up

Rebinding is reflected everywhere: menus, tooltips and the hints in the options strip all show your keys. The complete list of defaults is in [All shortcuts](../reference/shortcuts.md).
