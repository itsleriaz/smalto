# Welcome to Smalto

Smalto is a fast, small, modern pixel art editor and animator for Windows, macOS and Linux. It is free software (GPL-3.0). It reads and writes `.aseprite` files, so you can move between Smalto and other tools without converting anything.

This manual covers everything in the app. It is written to be read from the top, but each page stands alone: jump straight to the page you need from the sidebar, or press <kbd>S</kbd> to search.

## What's in here

- **[Getting started](getting-started/install.md):** install Smalto, find your way around the window and draw your first sprite.
- **[Drawing](drawing/tools.md):** the tools, brushes, pen and tablet support, symmetry, dithering, shading, selections and transforms.
- **[Layers and animation](layers-animation/layers.md):** layers and groups, frames, tags, onion skin, cels, and the particle and smear layers.
- **[Color](color/palettes.md):** palettes, indexed color, color modes and effects.
- **[Tilemaps and slices](tilemaps-slices/tilemaps.md):** tilesets, tile and pixel mode, and slices for game engines.
- **[Files](files/open-save.md):** opening, saving, importing, exporting, and the Aseprite file format.
- **[Customizing](customizing/panels.md):** panels, themes and shortcuts.
- **[Reference](reference/shortcuts.md):** every shortcut, a glossary and troubleshooting.

## Conventions in this manual

- Keys are written like <kbd>Ctrl</kbd> + <kbd>S</kbd>. On a Mac, read <kbd>Ctrl</kbd> as <kbd>Cmd</kbd>.
- Names of buttons, menus and fields are in **bold**: **File → Export…**.
- Every key has a default; you can rebind them in **Preferences → Shortcuts** (see [Shortcuts](customizing/shortcuts.md)).

> **Tip.** Hover any button in Smalto for its name and shortcut. The manual and the tooltips use the same words.
