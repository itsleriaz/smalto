# All shortcuts

These are the defaults. Rebind them in **Preferences → Shortcuts** (see [Shortcuts](../customizing/shortcuts.md)). On a Mac, read <kbd>Ctrl</kbd> as <kbd>Cmd</kbd>. <kbd>Esc</kbd>, <kbd>Enter</kbd>, <kbd>Delete</kbd>, <kbd>Backspace</kbd>, <kbd>Space</kbd> and the arrows keep their own jobs and can't be rebound.

> This page is generated from the app's shortcut table by `scripts/manual-shortcuts.py`. Don't edit it by hand.
